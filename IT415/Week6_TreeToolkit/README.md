# IT 415 – Week 6: TreeToolkit

**What this shows:** Binary tree traversals (inorder, preorder, postorder), height/depth utilities (edges convention), and a minimal BST (Insert, Contains). Includes a reflection at the top of TreeToolkit.cs.

**Files**
- Toolkit/Trees/TreeToolkit.cs – TreeNode + BST + traversals + height + demo runner
- (Optional) Yost_Kathy_Week6_TreeToolkit.docx + screenshot in this folder

**How to run**
1. Build the solution.
2. Run the console app that calls TreeDemo.Run() (see Program.cs).
3. Console shows traversal outputs, BST checks, and height comparisons (balanced vs. skewed).

**Notes**
- Unicode-safe reversing used for emoji in tests (ReverseTextElements).
- Reflection included at the top of TreeToolkit.cs (dated November 1, 2025).
